# Original-art VTC variant

`assets/vtc-authored-detailed/world.usda` is a standalone scene. Its meshes, materials and
surface pigments are generated by original recipes in `src/usim_env_vtc/`.
It does not sublayer the old VTC scene or reference its imported models,
textures, MDL files, hidden reference images or point-cloud display layers.
The old assets and road-repaired/detailed variants remain unchanged.

## Replacements

- All 367 standing trees: 118 existing trees and 249 LiDAR-supported additions.
  Broadleaf trees have tapered branching wood and individually folded leaves;
  pines have tiered branches and needle surfaces. Six vegetation recipes replace
  the original broadleaf, ornamental, pine, stump and shrub prototype families.
- All 331 native shrubs and the existing stump.
- All 50 City Hall components, including pillars, windows, entrance portals,
  floors, roofs, rails, counters and the stair flight.
- All displayed primitive structures, chairs, tables, cones and rocks.
- All terrain surface artwork, including imported grass/gravel/asphalt/tile
  textures and source-derived preview colors. New colors are procedurally
  generated from the five retained map-data surface masks.

There are 107 original prototypes and 1,039 replaced mesh placements. Sixty
formerly plain cuboid buildings have independently designed window/floor bands,
using 42 additional envelope variants. Their solid collision envelopes and
exact actor transforms remain unchanged. Twenty-two
hidden editor helpers, the imported sky sphere and the hidden reference marker
are omitted. The native viewer supplies its own sky/sun. Archived robot/sensor
exports are not scene dependencies.

Actor and native foliage coordinate frames are retained. Seven measured
column proxies remain original cylinder geometry. The corrected terrain retains
all 64 tiles, 4,096 components, 66,064,384 vertices and 130,056,192 triangles;
no road-height correction, topology or terrain collision detail is discarded.
The small VTC-authored BSP geometry remains as map data with new appearance.

Building shapes are original approximations fitted to dimensional envelopes,
not exact reproductions of the imported topology. City Hall has actual open
portals, perimeter window bays, thin floor/roof slabs and a 30-tread staircase
with an upper-floor aperture. The whole building is not a solid bounding box.
The two-meter stair flight follows the side of its source envelope, leaving
the original ground-floor table row clear instead of filling the entire box.
The baseline's other buildings remain envelope-level structures. Their new
facades are generic visual designs, not invented claims of surveyed detail.

## What licensing dependencies remain

The original generation software and independently authored recipe artwork use
the repository's MIT license. **The assembled geographic map is not blanket MIT
or established as commercially unrestricted.**

| Retained information | Provenance still relevant |
| --- | --- |
| Terrain heights and five road/land-cover masks | VTC landscape; GSI/DEM and fuRo 2020 contributions described in the existing audit. Downstream clearance remains unresolved. |
| Actor transforms, dimension envelopes and small BSP geometry | Original VTC placement/model metadata. Retained coordinates and dimensions are not newly surveyed or automatically relicensed. |
| 249 inferred tree and seven column placements | Registered official fuRo 2019 PCD, CC BY-NC-SA 4.0; attribution and map-data conditions remain. |

Removing model/texture bytes and all upstream artwork arcs eliminates the
runtime artwork dependencies on KiteDemo, Paragon, StarterContent, Engine mesh
exports, Megascans and imported leaf/bark/concrete/wood images. It does not prove
that metadata taken from CC City Hall/tree envelopes is unrestricted. Keep
source attribution and modification notices with the assembled map.
Original geographic data and the envelope-fitted scene still require their
respective terms to be considered before redistribution.

Attribution retained: VTC, copyright 2017-2020 Tomoaki Yoshida; fuRo and the
Tsukuba Challenge official 2019 dataset. See the pinned source links and detailed
conditions in [the existing asset audit](tsukuba-full-map/LICENSES.md).
No acquired asset pack is redistributed by this variant.

## Reproduce

Use the existing CPU reconstruction environment or temporary optional packages:

```sh
uv run --with usd-core==25.5.1 python src/usim_env_vtc/model_inventory.py \
  --assembly-report assets/vtc-full/assembly-report.json \
  --out runs/vtc-original/inventory.json

uv run --with usd-core==25.5.1 --with Pillow==11.3.0 \
  python src/usim_env_vtc/author_scene.py \
  --world assets/vtc-detailed/world.usda \
  --index assets/vtc-detailed/world.index.json \
  --inventory runs/vtc-original/inventory.json \
  --masks assets/vtc-full/terrain/shader-masks \
  --out assets/vtc-authored-detailed

uv run --with usd-core==25.5.1 python src/usim_env_vtc/verify_authored_scene.py \
  --world assets/vtc-authored-detailed/world.usda \
  --source assets/vtc-detailed/world.usda \
  --out runs/vtc-authored/verification.json
```

Generate into a new directory; the command does not replace existing USD files.
Inputs include dimensional metadata but no imported vertex, UV, normal, texture
or material arrays are copied into the new model prototypes. Retained terrain
and BSP geometry are explicitly separate map-data classes.

`authorship.json` records every replacement, exact actor matrix, omitted helper,
prototype mapping, seeds in each prototype's metadata and SHA256 output hashes.
`world.index.json` encloses actual generated payload geometry, including new
tree crowns. It is regenerated rather than retaining stale source bounds.
The recursive dependency check includes unloaded payloads and requires every
USD dependency to be inside `assets/vtc-authored-detailed`, with no texture/MDL assets.
`NOTICE`, `LICENSE-MIT` and `LICENSE-APACHE2` accompany the output; their inclusion
does not change the geographic data's terms.

For the native GUI, use the already configured separate Isaac environment:

```sh
python src/usim_env_vtc/native_view.py \
  --world assets/vtc-authored-detailed/world.usda \
  --index assets/vtc-authored-detailed/world.index.json \
  --out runs/vtc-authored/view \
  --region 2 5 --oblique --interactive
```

The matching inspection SDK and `anyio==4.11.0` are documented in
`src/usim_env_vtc/requirements-isaac.txt`. Keep these dependencies isolated from
the simulator backend and from downstream applications.

Native QA captures are under `runs/vtc-authored/final-city-front/` and
`final-city-rear/`; both opposite sides of the completed facades were inspected.
The internal stair/furniture check is under `final-city-interior-lit/`, using
QA-only fill lights from `interior-inspection.usda`; these do not change the
distributed map. The unlit inspection remains separately recorded.
Use one QA render process at a time: a concurrent launch of this SDK crashed
during native startup, and a completed capture can still hang during SDK shutdown.
This affects the inspection runtime, not a dependency on the replaced assets.

## Verification record

`runs/vtc-authored/verification.json` identifies the final world and verifies
1,039 exact actor transforms, all 1,110 conservative payload bounds, all 178
generated USD hashes, every repaired terrain vertex/triangle/component, seven
measured post colliders, and the 60 generic facades / 42 facade prototypes.
All runtime dependencies are inside the output directory; external model,
texture and MDL assets and unresolved assets are zero.

Repository lint, formatting, the 256 base tests (14 optional-environment skips),
100 targeted CPU/USD regression tests, and source/wheel builds passed.
The editor's base environment still reports unresolved optional USD/import
paths; the actual generators, tests and native GUI ran in explicitly supplied
isolated environments. No type errors or test failures were suppressed.
