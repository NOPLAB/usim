# Provenance

The initial engine code and demonstration worlds were extracted from
[NOPLAB/rvln](https://github.com/NOPLAB/rvln), commit
`6728fc318d3cef53cf0b5a469c0c9e8bb794b104`.

Only generic robot authoring, simulation contracts, standard ROS I/O and engine
ports belong here. Application inference, evaluation, protocols and robot-specific
adapters remain with their consumers. Historical runtime environments and data
were not moved or removed. The owned source is MIT licensed.
